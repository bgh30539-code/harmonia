# Support

Welcome! This page tells you how to get help with Harmonia.

## Before asking

- Read the **[README](README.md)** — it covers installation, usage, keyboard
  shortcuts and a troubleshooting table.
- Check the **[FAQ](README.md#faq)** section.
- Search the **[issues](https://github.com/bgh30539-code/harmonia/issues)**
  (open and closed) — your question may already be answered.
- Check the **[CHANGELOG](CHANGELOG.md)** — the answer may be a known change.

## Where to ask

| Need | Where |
| --- | --- |
| Bug report | [Open an issue](https://github.com/bgh30539-code/harmonia/issues/new?template=bug_report.yml) with steps to reproduce and logs |
| Feature request | [Open an issue](https://github.com/bgh30539-code/harmonia/issues/new?template=feature_request.yml) |
| Installation / build problems | [docs/INSTALL.md](docs/INSTALL.md), then an issue if still stuck |
| Security vulnerability | [SECURITY.md](SECURITY.md) — **private** reporting |
| Everything else | [Open an issue](https://github.com/bgh30539-code/harmonia/issues/new) and label it appropriately |

## Writing a good bug report

A great bug report includes:

- Harmonia version and **platform** (Linux distro / Windows / Android version)
- What you did, what you expected, and what happened instead
- Steps to reproduce, ideally from a clean state
- Any relevant log output (Harmonia logs to stderr and a rotating log file in
  the app-data directory)
